---
name: meeting-memory
description: Analyze an authorized meeting against a local Markdown knowledge base and update its existing records without duplicate archives.
---

1. Start from the canonical meeting ID, manifest and any continuation. Read the
   complete transcript; identify unresolved questions, decisions and evidence gaps.
2. Search the configured vault by participants, project names, concepts and previous
   decisions. Read the most relevant original records, not just matching lines.
   Record the actual search and what history supports, changes or contradicts.
3. Develop a layered analysis with useful comparison tables where appropriate.
   Connect meeting evidence and history to reasoning, tradeoffs and concrete next
   steps. Keep facts, inference, advice and unknowns distinguishable. Preserve
   original-language quotes and uncertainty about speakers.
4. Keep raw evidence immutable. Update the source summary keyed by the same meeting
   ID, the index and genuinely affected existing notes. Do not create duplicates.
   In a new vault explicitly note the absence of history. Synthetic tests must not
   create real personal tasks or overwrite real knowledge.
5. Follow the supplied WORKFLOW.md output contract. Check the analysis is useful
   independently of links. Save partial results on interruption and resume them.
